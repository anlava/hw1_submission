# Методика проверки: положение двух изохрон M67 на диаграмме цвет–величина

[порождено] Проект методики от 08.11.2026. Разделы 0–7 фиксируются отдельным коммитом до первого прогона **нового** эксперимента. Прежние CSV и графики M67 уже существовали; это исходный материал, а не результаты данного сравнения.

## 0. Паспорт

| Поле | Значение |
|---|---|
| Проект | `cluster_isochrones`; астрофизика, рассеянное скопление M67 (NGC 2682) |
| Что проверяем | Расчёт отклонения звезды по цвету от модельной линии при той же видимой величине G |
| Ветка недели 6 | Тесты на свойствах: численная сверка с аналитически известным ответом и проверка на испорченной версии |
| Исходная версия | Файлы из коммита `1334a49` рабочего проекта. Метка в конце недели 6: `exp-verifier` (план). |

## 1. Замысел

**Вопрос.** Где и насколько реконструкции по параметрам Cavallo и Bossini отклоняются по цвету от наблюдаемых звёзд на участке главной последовательности M67?

**Гипотеза.** При фиксированных параметрах публикаций величина отклонения может зависеть от яркости. До расчёта не назначаем одну модель лучшей. Сравниваем обе кривые на одних и тех же звёздах внутри каждого интервала G.

**Ответ.** Таблица по интервалам G: число звёзд, знак и величина типичного цветового отклонения для каждой модели, разница между моделями с оценкой неопределённости. Отдельный результат — вердикт верификатора вычислений.

## 2. Постановка

- Исходная выборка — уже проверенные члены M67 с конечными G, BP, RP и G ≤ 18. Новых отсечений по вероятности членства, цвету или близости к одной из моделей нет.
- Заранее выбираем три интервала видимой G (mag): **[15, 16), [16, 17), [17, 18]**. Цель — сравнить линии на более слабом участке, в стороне от ярких эволюционных ветвей. Это выбор протокола, а не уже проверенное утверждение об однозначности кривых.
- Для каждой изохроны берём фазу главной последовательности: рабочий код `label=1`; при подготовке реализации сверить его с легендой использованной версии [CMD/PARSEC](https://stev.oapd.inaf.it/cgi-bin/cmd_3.9). Если значение не подтверждено, остановиться. Используем только отрезки между соседними точками одного непрерывного блока этой фазы в исходной таблице. Разрывы не соединяем.
- Обе модели должны задавать **единственный модельный цвет** на всём диапазоне 15 ≤ G ≤ 18. Цвет находим линейной интерполяцией по отрезку, содержащему данную G. Общая вершина соседних отрезков учитывается один раз. Экстраполяция, разрыв покрытия или несколько разных цветов при одной G недопустимы. Если условие не выполнено, прекращаем обработку до расчёта остатков; новую область, если понадобится, обосновываем и фиксируем отдельной версией методики.
- Используем готовые `G_app` и `BP_RP`: модуль расстояния и поглощение повторно не применяем. Возраст, металличность, расстояние и поглощение не подбираем.

## 4. Код и окружение

Планируемые файлы: `src/m67_residuals.py` — интерполяция, расчёт остатков и запуск эксперимента; `checks/test_m67_residuals.py` — независимые контрольные примеры. Ожидаемые ответы в тестах получаются из аналитической формулы, а не вызывают проверяемую интерполяцию.

Команды ниже выполняются из корня проекта в отдельном окружении Python 3.11+ с NumPy, pytest и Hypothesis. Фактические версии интерпретатора и используемых пакетов записываем вместе с первым прогоном. Указанные команды — контракт для предстоящей реализации; сами прогоны здесь не заявлены.

## 5. Верификатор

Для звезды с цветом C = BP − RP и величиной G вычисляем **r = C − C_model(G)**, в mag. Положительный r означает, что звезда краснее модели; отрицательный — синее.

Контрольная линия: C_ref(G) = 0.70 + 0.20 × (G − 15); модели передаются только узлы при G = 15, 16, 17, 18. Тестовые звёзды ставятся **между** узлами и отдельно на границах. Их цвет задаётся напрямую формулой C_ref(G) + s. Тогда для каждой звезды заранее известно r = s. Проверяем s = −0.05, 0, +0.05 mag. Сравниваем каждую точку, а не только медиану.

Команда проверки: `python -m pytest checks/test_m67_residuals.py -q`. При реализации её следует записать в критерий готовности этого этапа в `AGENTS.md`. Для демонстрации создаём отдельную ветку и коммит с внесённой ошибкой: меняем знак остатка в производственной функции. На звезде со сдвигом +0.05 ожидается +0.05, а испорченная функция вернёт −0.05. На обеих версиях запускаем одну и ту же проверку; защищённые тесты и исходные данные не меняем.

## 7. Правило принятия (до запуска)

**Вычисление принято**, если максимальное |r − s| на контрольных точках ≤ 10⁻⁸ mag во всех девяти прогонах; нарушение покрытия и неоднозначная ветвь корректно отклоняются; испорченная версия даёт код 1 у pytest, исправная — 0. Абсолютный допуск 10⁻⁸ mag взят из численной сверки CSV в проекте. Это допуск программы, а 0.05 mag — заданный контрольный сигнал. Ни одно из этих чисел не является оценкой фотометрической ошибки Gaia.

**Сравнение на M67.** В каждом интервале сообщаем отдельно для каждой модели медиану r (направление смещения) и медиану |r| (типичная величина отклонения). Для сравнения определяем D = median(|r_Cavallo|) − median(|r_Bossini|). При D > 0 типичное отклонение по цвету меньше у Bossini; при D < 0 — у Cavallo. Если в интервале меньше 20 уникальных звёзд, показываем число объектов и отметку «недостаточно данных», без вывода о моделях. Число 20 — заранее выбранный рабочий минимум; интервалы после просмотра не объединяем.

**Неопределённость.** Внутри каждого интервала пересэмплируем звёзды с возвращением, сохраняя пары остатков Cavallo/Bossini для одного GaiaDR3. Делаем по 2000 повторов для каждого seed 11, 23, 37; объединяем 6000 значений D, не выбирая лучший seed. Для трёх запланированных сравнений используем процентильный интервал с границами α/(2 × 3) и 1 − α/(2 × 3), где α = 0.05. Если интервал включает ноль, записываем «устойчивого различия не обнаружено». В любом случае приводим D в mag. Физически важный порог не назначаем без отдельного обоснования.

Для завершения научного расчёта не требуется превосходство какой-либо модели. Неопределённость учитывает состав данной выборки, но не ошибки параметров публикаций и не все систематические эффекты.

## 10. Ограничения

В пределах выбранной яркости анализируются все звёзды исходной выборки, без выделения последовательности одиночных звёзд. Двойные и возможные нечлены могут менять остатки. Метрика измеряет отклонение по цвету при фиксированной G, а не кратчайшее расстояние на CMD. Точка поворота, другие ветви, дополнительный отбор по Prob и подбор возраста не входят в этот эксперимент. Разница между двумя фиксированными наборами параметров сама по себе не указывает, какой отдельный параметр её вызвал.
